# Naikaku AI Togo System v0.1.1 リリースノート

Naikaku AI Togo System v0.1.1 は、合同会社EMYSTIが開発・公開する公式公開版アップデートです。

本リリースでは、単なるモックや静的計画にとどまらず、実際に隔離作業ツリー（Worktree）内でコードを編集し、テストランナーを回して査問・合否判定を行う**「自律目標達成エンジン (/goal)」**と、API キー不要・完全オフライン動作可能な**「Ollama（ローカル LLM）ネイティブ連携」**を正式導入しました。

---

## 主な新機能と改善点

### 1. 自律目標達成エンジン (`/goal` / `naikaku goal`)
従来の事前計画作成（`prepare`）モードに加え、内閣の多重合議・相互牽制による自律反復ループを実装：
- **総理府審議 (Prime Minister)**: 目標受付、納品物要件および合否検収基準（Definition of Done）の策定。
- **政策戦略担当 (Strategy Minister)**: 対象作業ツリー構造の解析、ファイル変更計画およびテスト計画の策定。
- **デジタル執行担当 (Digital Execution Minister)**: 隔離された sandbox worktree 内でコードを安全に書き込み、実テスト（Vitest 等）をサブプロセスで実行。標準出力・エラー・Exit Code を完全記録。
- **野党査問役 (Opposition Critic)**: テスト結果、差分（Git Diff）、未対応の境界値を厳しく査問。Exit Code が 0 以外の場合は欠陥（Flaws）を挙げて即時差し戻し（REVISE）。
- **国家公安監査 (Public Safety Auditor)**: パストラバーサル攻撃（`../../` 脱出）や危険コマンドパターンをリアルタイムで検知・遮断。
- **閣議採決 (Cabinet Ratification Vote)**: 準備度・執行度・野党査問・安全性の 4 軸で総合採点（100点満点）。**75点以上の場合のみ SHIP（完成批准）**。

### 2. 本機ローカル LLM（Ollama）ネイティブ対応
- API キー不要・完全オフライン・ゼロコストで動作可能。
- `naikaku doctor` コマンドで本機の Ollama 稼働状況を自動検出。
- Qwen 2.5-Coder、Llama 3、DeepSeek などのローカルモデルと即時連携。

### 3. 改竄防止セッション受領書と Git 統一差分
- 閣議で承認された作業には、SHA-256 ハッシュ付きセッション受領書（`receipt.json`）、Git 統一差分（`git.diff`）、監査証跡パッケージ（`evidence.json`）が自動出力されます。

### 4. 領域別自律合成テンプレートの拡充
- 入力値検証（Email・数値範囲バリデータ）
- 認証・パスワード強度スコアリング
- スライディングウィンドウ方式のインメモリレートリミッター
- TTL 有効期限付きインメモリキャッシュストア

### 5. Web ワークベンチ UI の `/goal` パネル
- ブラウザ上でリアルタイムに閣議審議タイムライン、野党指摘事項、Git Diff 差分ビューワー、受領書ダウンロードを利用可能。

## クイックスタート

```bash
# クローンと依存導入
git clone https://github.com/YAHATAKAHA/naikaku-ai-togo-system.git
cd naikaku-ai-togo-system
npm ci

# 2秒スモーク検証（自律バリデータ作成・Vitest実行・94点SHIP承認）
npm run goal:smoke

# 本機 Ollama を使った自律ミッションの実行
npm run naikaku:goal -- "Implement sliding window rate limiter with unit tests" --provider ollama
```
