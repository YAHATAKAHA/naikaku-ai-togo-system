# Naikaku AI Togo System v0.1.1 Release Notes

Naikaku AI Togo System v0.1.1 is an official public-source update developed and maintained by 合同会社EMYSTI (EMYSTI LLC).

This release introduces the **Autonomous Cabinet Goal Engine (`/goal`)** and **Native Offline Ollama Support**, bridging the gap between static task planning and genuine, sandboxed, self-verifying software engineering.

---

## Highlights

### 1. Autonomous Cabinet Goal Engine (`/goal` / `naikaku goal`)
Moves beyond static preparation mode into a governed, multi-agent deliberation and execution loop:
- **Prime Minister**: Establishes deliverables and acceptance criteria (Definition of Done).
- **Strategy Minister**: Inspects target worktree files, formulates file modification plans and test execution commands.
- **Digital Execution Minister**: Modifies code inside an isolated worktree and executes real test runners (Vitest) in subprocesses, capturing exit codes and stderr.
- **Opposition Critic**: Strictly scrutinizes exit codes, failures, and diffs. Non-zero exit codes automatically trigger flaw notifications and revisions (REVISE).
- **Public Safety Auditor**: Real-time detection and blocking of path traversal attacks (`../../`) and dangerous shell patterns.
- **Cabinet Ratification Vote**: Scores Readiness, Execution, Critique, and Safety. Code is ratified to **SHIP only when score >= 75/100**.

### 2. Native Open-Source Local LLM Support (Ollama)
- 100% offline, zero-secret autonomous execution with zero inference fees.
- Automatic detection via `naikaku doctor`.
- Works out of the box with Qwen 2.5-Coder, Llama 3, DeepSeek, etc.

### 3. Tamper-Evident Session Receipts & Unified Diffs
- Completed goals generate cryptographically sound session receipts (`receipt.json`), full unified diffs (`git.diff`), and audit evidence packages (`evidence.json`).

### 4. Expanded Domain Synthesis Templates
- Input validation (Email & numeric range validators).
- Authentication and password complexity scoring.
- In-memory sliding-window rate limiters.
- In-memory TTL key-value cache stores.

### 5. Web Workbench `/goal` Panel
- React UI featuring real-time Cabinet deliberation timeline, critique flaw lists, live Git Diff inspector, and receipt download.

## Quick Start

```bash
git clone https://github.com/YAHATAKAHA/naikaku-ai-togo-system.git
cd naikaku-ai-togo-system
npm ci

# Run 2-second smoke verification
npm run goal:smoke

# Run autonomous mission with local Ollama
npm run naikaku:goal -- "Implement sliding window rate limiter with unit tests" --provider ollama
```
